filtered-retrieval-bench ↗

Benchmark · pgvector, Supabase, Row Level Security

Vector search under Postgres Row Level Security returned nothing for most users, with no error. I built a benchmark (57,600 embeddings, 648 questions) to measure it, then fixed it without changing the security policy: recall@10 of 0.96 or higher at a median latency of 11 ms or less.

I then turned it into a regression eval for AI coding agents, submitted to Supabase (open PR #488). It caught Claude Code returning results in the wrong order.

Lesson: the worst retrieval bugs don't throw errors. They just return less.

moderate → strongLLM judge agreement with human labels

LLM judge for agent answers

Fieldforce · evaluation

I built an LLM judge that grades an agent's answers for faithfulness and clarity, and measured it against human labels with Cohen's kappa. Splitting "is it well written" and "is it honest" into separate rubric items raised agreement from moderate to strong.

Lesson: a judge that mixes style and honesty in one score will reward confident wrong answers.

  • LLM-as-judge
  • Cohen's kappa
  • Langfuse
